# 七、模块级状态管理

只有跨页面共享状态才进入 Pinia。

例如：

```text
当前用户
当前门店
权限
全局字典
```

页面临时状态优先：

```text
ref
reactive
computed
```

不要为了使用 Pinia 而使用 Pinia。

---



# 八、门店数据隔离

凡涉及门店的数据必须确认：

```text
当前 storeId
允许 storeIds
dataScope
```

前端不得：

```text
手动修改 storeId 绕过权限
```

切换门店后：

```text
清除旧门店页面缓存
刷新当前页面
重新获取门店相关数据
```

# 九、权限

```

```

不能只控制菜单而不控制按钮。

# 十一、模块开发禁止事项

禁止：

- 擅自增加业务功能
- 擅自修改 API
- 擅自修改 DB
- 绕过权限
- 前端伪造后端数据
- 用 Mock 数据代替正式 API
- 为了页面方便修改业务规则
- 复制后端业务算法到前端
- 一个模块修改大量无关模块
