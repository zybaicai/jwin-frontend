| ID | 风险 | 说明 |

| P0-1 | 消耗撤销后预约状态是否回退 | 创建消耗时 `bindTreat`+`markCompletedByTreat` 直接 DONE；**未见撤销消耗回滚预约**的专门逻辑 → **待业务确认**；若门店会作废消耗，可能出现「预约已完成但消耗已销」 |
