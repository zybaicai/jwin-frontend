## 7. 失败 / 未执行项

1. **同格 ≥3 人溢出弹窗**：未造三预约同格数据。  
2. **到店→开消耗→消耗单关联完整 UI E2E**：接口与入口已有，本轮未走完整收银扣减。  
3. **无权限越权账号隔离**：仍缺独立测试账号。  
4. **飞书 / 短信 / 微信实发**：按指令不做。  
5. **预约类型写接口**：只读展示 TB_AppointmentType。  
6. **个别历史班次名称乱码**：库内旧数据，不影响排班逻辑；需手工改名时可走班次编辑。
