============================================================
五、接口业务含义
============================================================

这个接口不是：

销售订单列表。

也不是：

销售订单详情里的 payments 简单前端展开。

它代表：

【该客户销售单的支付流水】

数据来源：

TB_SaleBillPay

并且：

一行 = 一笔支付。

因此：

一张销售订单如果：

微信 500
现金 300
储值卡 200

支付明细应该有：

3 行。

不能合并成一行。

page

九、支付明细返回字段
============================================================

API 文档定义：

{
  "billId": "S20260801001",
  "billType": "销售",
  "storeId": 1001,
  "storeName": "杭州A店",

  "payMethodName": "微信",
  "payAmount": 1280.00,
  "orderAmount": 1280.00,

字段含义：

订单编号

billType：
订单类型

开单门店

employeeName：
开单人/录单人

totalAmount：
订单金额，即销售单 TotalAmount

payType：
支付类型

payMethodName：
支付方式

payAmount：
本笔支付金额

orderAmount：
下单金额，即销售单 Amount

createdOn：
录单时间

最终必须以当前后端真实 VO 为准。
