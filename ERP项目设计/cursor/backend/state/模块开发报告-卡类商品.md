## 5. API

- `/api/v1/cards/general|time|saving|package`：列表/详情/创建/更新/停售  
- `/api/v1/saving-card-discounts`：区域折扣 CRUD/停用  

## 6. 权限

`card:general|time|saving|package:view|edit`；`card:saving-discount:view|edit`；均 `storeCheck=false`。

## 7. 业务规则

- 次卡设计单次价值展示 = `Price/Amount`（不落项目单价列）  
- 套餐明细合计**不强制**=卡售价  
- 储值本金/赠金分列；区域折扣 = PriceArea×Project×Rate×窗；Active 窗**禁止重叠**  
- B-05 本模块只加列；快照写入留销售开户  
- 卡类不走项目 PriceResolution；金额 BigDecimal  

## 8. 事务

写操作 `@Transactional`（create/update/deactivate/replaceProjects）。

## 9. 并发
