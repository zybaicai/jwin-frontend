## 逐条问答（表）

| # | 问题 | 回答 |
|---|---|---|
| 1 | 为什么必须改库？ | 旧 `TB_Channel` 是渠道商，不能当收银销售方式字典；指导书要求配置化 |
| 2 | 原表能否复用？ | 单据 `Channel` 字符串可复用；字典不能复用 TB_Channel |
| 3 | 原字段能否复用？ | 字典侧无对应字段可挂 |
| 4 | 为什么不能复用？ | 语义冲突（渠道商 vs 销售方式） |
| 5 | 新字段 | ID, Code, Name, ParentID, Sequence, Active, Remark |
| 6 | 类型 | int / nvarchar(50) / bit |
| 7 | NULL | Remark 可空；其余 NOT NULL |
| 8 | 默认值 | ParentID=0, Sequence=0, Active=1 |
| 9 | 旧数据 | 不影响；历史单据 Channel 自由文本保留 |
| 10 | BI | 新维表；单据仍读 Channel 字符串；新单将写 Code |
| 11 | 旧系统 | 新表旧系统不写则无感；不改旧表 |
| 12 | 可回滚 | DROP TABLE TB_SaleChannel（确认无依赖后） |
| 13 | 迁移 | 仅种子插入；无历史回填 |
| 14 | 人工确认 | C-01/CONF-007 已确认；本审查风险 **P3** |
