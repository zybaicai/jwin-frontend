## 5. API

- `POST /api/v1/sales/orders` 创建（可带支付直接完成）
- `GET /api/v1/sales/orders/{id}` / `GET /api/v1/sales/orders` 详情/列表
- `POST /api/v1/sales/orders/{id}/close` 关闭未支付
- `POST /api/v1/sales/orders/{id}/pay` 收款完成
- `GET /api/v1/payments/methods` 支付方式
- `POST /api/v1/saving-card-accounts/{accountId}/arrear-repay` 最小平账

## 6. 权限

`sale:order:view|create|pay|close|backdate`；`sale:arrear:repay`；门店校验随注解。

## 7. 业务规则

- **CONF-007/009**：强制叶子 `saleChannelId`；项目走 `SalePricing`/`PriceResolution`；卡类=定义价；禁止前端定最终价  
- **CONF-010**：handlers ≥1，比例合计 100% → `TB_SaleBillHandler*`  
- **CONF-011**：`billDate` 本月内 ≤ 今天；补单需 `sale:order:backdate`；`CreatedOn=GETDATE()`；报价按 BillDate  
- **CONF-012**：欠尾款；储值 `Balance=面值-欠款`；赠金仅 `largessAmount` 显式；平账减欠增可用  
- **CONF-013**：业绩/账户 EntityID=开单店；不改 `IsBelongEntity`  

## 8. 事务

`create` / `pay` / `close` / `repay` 均 `@Transactional`；支付成功同事务发卡+业绩。

## 9. 并发

IdGenerator max+1；平账金额 ≤ 当前欠款（乐观依赖事务）。
