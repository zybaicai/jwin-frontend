## 逐条回答（同义词 + 视图）

1. **为什么必须改？** 物理表名/列名含 `CHAR(10)`，Mapper 无法稳定书写。  
2. **原表能否复用？** 能；同义词/视图指向原对象。  
3. **原字段能否复用？** 能。  
4. **为何不能只靠原名？** 换行标识符在 XML 中易损坏。  
5～8. **新对象：** 同义词 + 只读视图；无新业务列。  
9. **旧数据？** 不改数据。  
10. **BI？** 无破坏；视图只读。  
11. **旧系统？** 不 rename 物理表。  
12. **可回滚？** DROP SYNONYM / DROP VIEW。  
13. **迁移？** 无。  
14. **人工确认？** CONF-036 A 已确认复用快照表；视图为访问封装。
