# 10《模块验收报告》

## 验收结果

# PASS

## 模块名称

角色中心（权限角色定义 / 绑功能码 / 员工角色+组织范围 / 登录强制）

## 功能范围

- 复用 `TK_JobType` 作权限角色定义（CRUD + Active）  
- `GET/PUT /job-types/{id}/permissions` 绑功能码  
- `GET/PUT /employees/{id}/role-access` 配置权限角色 + 组织范围  
- 员工人事接口权限加固  
- `GET /roles` 系统角色只读；无 TB_Role 管理写接口  
- 删除角色时拦截人事引用与权限角色绑定  
- 登录强制：有权限角色 + 有组织范围且能展开门店  

## API

| 方法 | 路径 | 权限 |
|---|---|---|
| GET/PUT | `/api/v1/employees/{id}/role-access` | org:role:view\|edit |
| CRUD | `/api/v1/employees`… | org:employee:view\|edit |
| CRUD | `/api/v1/job-types` | org:job:view\|edit |
| GET/PUT | `/api/v1/job-types/{id}/permissions` | org:role:view\|edit |
| GET | `/api/v1/roles` | org:role:view |

## 权限

`org:role:*`、`org:job:*`、`org:employee:*`（种子已有）。
