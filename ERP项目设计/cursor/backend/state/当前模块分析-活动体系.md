## 1. 模块目标

配置**统一活动**与**单店特殊活动**（时间、项目、活动价、适用门店、适用销售渠道），并在开单按渠道列价/选渠道报价时，对命中渠道返回活动价（`priceSource=ACTIVITY`）。

## 2. 业务范围

**做：** 活动头/明细/门店范围 CRUD；报价渠道内活动覆盖；权限；单测；API 文档。  

**不做：** 特价审批（C-06）、临时改价（C-07）、销售单据 ActivityID 快照、小程序 `TM_Groupon*`/`TM_Seckill*`。

## 3. 与已确认规则对齐

| 规则 | 本模块落地方式 |
|---|---|
| CONF-009 | 仍列叶子渠道；活动是**该渠道展示价的时段覆盖**，不是另开渠道、不恢复瀑布 |
| CONF-001 卡类 | 套餐/次卡/时效不走普通项目活动价 |
| 金额 | BigDecimal |
| 00 数据库第一 | C-04/C-05/+Store 新表须 **08 → 人工确认 → 执行** |

## 4. 数据库（待 08）

- `TB_Activity`（含 `ActivityType`、`AllStores`、时间、Active）  
- `TB_ActivityPrice`（ActivityID + ItemType + ItemID + SaleChannelID + Price）  
- `TB_ActivityStore`（非全店时）

## 5. 代码落点（计划）

- 改：`PriceResolutionService`（同渠道解析最前插入活动匹配）

## 6. 已锁定约定

- `AllStores=1`：统一活动全部门店；单店特殊禁止全店、必须配门店  
- 重叠：`BeginDateTime` 最晚 → 同则 ID 最大  
- 停用优先于物理删除（有引用时）
