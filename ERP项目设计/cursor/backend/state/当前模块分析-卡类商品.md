## 1. 模块目标

卡类商品**产品设计（Definition）**：通用次卡、时效卡、储值卡、套餐卡的主数据与设计价值/范围配置；储值**价格区域折扣**；B-05 列就绪。

定位：指导书「卡类商品中心」的设计切片，**不重做**售卡开户 / 耗卡 / 退款收银流。

## 2. 业务范围摘要

**做：** 四卡 CRUD/停售；次卡/时效项目范围；套餐明细设计价；储值本金赠金；区域折扣；B-05 DDL；权限与单测。  

**不做：** 销售写账户与快照写入、耗卡扣减、退款审批、卡走 `PriceResolution` 渠道价、会员主档。

## 3. 与已确认规则对齐

| 规则 | 本模块方式 |
|---|---|
| CONF-001 卡类不走普通项目价 | 定义价在卡表；禁止改报价链吃卡 |
| CONF-008 / B-05 | 本模块 **只加列**；销售开户再写入 |
| CONF-003 退款×快照 | 退款模块；本模块备列 |
| 储值区域折扣 | C-08 配置；耗卡时查询（本模块提供 Query） |
| 00 数据库第一 | 定义表 **优先复用**；新列/新表须 **08→确认→执行** |
| 金额 | BigDecimal |

## 4. 已锁定约定（开发不得擅自改）

| # | 约定 |
|---|---|
| 1 | V1 = **定义 + 折扣**；开户/耗卡/退款不在本 05 |
| 2 | 次卡单次设计价值 = `Price/Amount` 展示，**不**在 `GeneralCardProject` 落单价列 |
| 3 | 套餐明细合计 **不强制** = 卡售价；行内 `Price×Amount` 与 `TotalPrice` 自洽 |
| 4 | 储值 `Price`=本金、`LargessPrice`=赠金，禁止混用 |
| 5 | 区域折扣有效期 **禁止重叠生效**（同 PriceArea+Project） |
| 6 | V1 套餐优先 `PackageCardProject`；Product/子卡明细做最小可用维护 |
| 7 | API 只暴露业务必需字段；旧表拼音等字段不强制进 VO |
