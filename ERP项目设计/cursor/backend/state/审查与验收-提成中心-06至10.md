# 10《模块验收报告》

## 验收结果

# PASS

## 模块名称

提成中心（销售提成 + 消耗提成：月度批算 + 快照 + 查询）

## 功能范围

- 按 `month`+`storeId` 批算项目路径销售/消耗提成并写入员工提成快照  
- 销售：成交额×Handler.Scale，规则优先级 JobType>Handler>Project>Scheme，无阶梯  
- 消耗：员工月业绩落入 `TK_EmployeeCommission` 阶梯；Fixed 每员工每月计一次  
- 同月覆盖重算；整单已退款销售/已取消·已退款耗卡不计入  
- 门店数据范围校验；权限点可配置

| POST | `/api/v1/commissions/calculate` | commission:calculate |
