## 验收结果

# PASS

## 模块名称

销售订单（开单 / 收款 / 补单 / 欠款 / 平账）

## 功能范围

- 创建销售单：强制叶子销售渠道、经手人比例、可选补单业务日、可选欠尾款与显式赠金  
- 服务端取价（项目报价按 BillDate；卡类定义价）；改价受权限  
- 收款关单 → 发卡入账（储值 Balance=面值−欠款；次卡 UnitPriceSnapshot）→ 开单门店业绩  
- 关闭未支付单；支付方式列表  
- 储值欠款最小平账 API  
- 跨店：所属店与开单店分离展示；不改写所属门店
