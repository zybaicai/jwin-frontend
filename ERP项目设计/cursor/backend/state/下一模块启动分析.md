# 下一模块启动分析：经手人配置与可选名单

> 依据：00 / 12；指导书经手人相关；现码销售/耗卡开单 `handlers`；旧表 `TB_*SaleHandler` / `TB_*TreatHandler` + `*JobType`  
> 时间：2026-09-16  
> **等待人工确认 Q1～Q5 后再执行 05。禁止未确认直接开发。**

---

## 1. 需求摘要

前端需要两块能力：

1. **配置 CRUD**：统一配置「哪些门店 / 组织 / 职务」可作为某类业务的经手人（销售/耗卡 × 项目/产品/储值/次卡/时效/套餐等）。  
2. **开单选人查询**：按当前开单门店 + 业务类型，返回可选员工名单（本店 + 符合条件的跨店），供销售单/消耗单勾选经手人。

---

## 2. 现码与旧库事实

| 项 | 现状 |
|---|---|
| 开单写经手人 | 销售/耗卡已支持多人+比例；缺「可选名单」API |
| 经手人类型解析 | 耗卡/销售写单时 `SELECT TOP 1 ID FROM TB_*Handler WHERE EntityID=? AND Active=1`；**未配则报错** |
| 旧表 | 已按品类拆分：`TB_ProjectSaleHandler`、`TB_ProjectTreatHandler`、`TB_ProductSaleHandler`、`TB_SavingCardSaleHandler`… + 对应 `*HandlerJobType`（HandlerID↔JobTypeID） |
| 行数 | 相关 Handler 表 **约 0 行**（可安全做 CRUD 灌数） |
| 跨店员工 | 已有 `GET/POST /stores/{storeId}/cross-store-employees`（`TK_EmployeeEntity` 非主店） |
| 员工职务 | `TK_JobType` + 员工职务绑定（多职务并集已在权限中心落地） |
| 统一配置 API | **无** |
| 开单可选经手人 API | **无** |

## 3. 推荐方案（待确认）

### 方案 A（推荐）：复用旧 `TB_*Handler` + `*JobType`，上层做统一 Facade

- **不新建**经手人主数据表。  
- Application 层用 `bizType` 枚举路由到对应旧表（如 `PROJECT_SALE` → `TB_ProjectSaleHandler` + `TB_ProjectSaleHandlerJobType`）。  
- CRUD：按门店维护「经手人角色」头（Name/Sequence/Active）+ 绑定职务列表。  
- 选人：当前门店员工 ∪ 本店跨店员工 → 过滤 `State=在职` → 职务与该 `bizType` 下本店 Active Handler 的 JobType 集合相交 → 再按调用方数据范围裁剪。

### 方案 B：新建统一表 `TB_ErpHandlerConfig`

- 一表多 `bizType`；与旧表双写或废弃旧表。  
- **违背「能复用不新建」**；且提成匹配仍依赖旧 `Project*HandlerID`，成本高。  
- **不推荐 V1。**

## 4. 拟议 API（确认后写入 API 文档）

### 配置（管理端）

```HTTP
GET    /api/v1/handler-roles?storeId=&bizType=
POST   /api/v1/handler-roles
PUT    /api/v1/handler-roles/{id}?bizType=
DELETE /api/v1/handler-roles/{id}?bizType=   # 建议停用 Active=0，非物理删
PUT    /api/v1/handler-roles/{id}/job-types  # 覆盖职务绑定
```

请求示例：

```JSON
{
  "bizType": "PROJECT_SALE",
  "storeId": 1002,
  "name": "护理师",
  "sequence": 1,
  "jobTypeIds": [1, 2]
}
```

### 开单选人（收银端）

```HTTP
GET /api/v1/handler-candidates?storeId=&bizType=&keyword=
```

返回：

```JSON
{
  "bizType": "PROJECT_TREAT",
  "handlerRoleId": 12,
  "handlerRoleName": "护理师",
  "employees": [
    { "employeeId": "E001", "name": "张三", "jobTypeIds": [1], "crossStore": false }
  ]
}
```

权限建议：`handler:config:view|edit`；选人可用 `sale:order:create` / `treat:order:create`（或独立 `handler:candidates:view`）。
