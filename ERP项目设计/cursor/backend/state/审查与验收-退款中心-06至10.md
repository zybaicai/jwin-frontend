# 10《模块验收报告》

## 验收结果

# PASS

## 模块名称

退款中心（销售退 / 耗卡退：申请 → 审批 → 执行）

## 功能范围

- SALE：按账户剩量×快照（次卡）/ 未耗本金（储值）服务端计价；审批后执行；仅停用退款明细账户；无剩余权益时冲业绩并标源单已退款  
- TREAT：审批后加回次数/储值、冲业绩、源单已退款；与本月取消互斥  
- 列表/详情门店隔离；支付方式无盲 fallback  
- 创建条件插入防并发双单  

## API

| 方法 | 路径 | 权限 |
|---|---|---|
| POST | `/api/v1/refunds` | refund:order:create |
| GET | `/api/v1/refunds` | refund:order:view |
| GET | `/api/v1/refunds/{id}` | refund:order:view |
| POST | `/api/v1/refunds/{id}/approve` | refund:order:approve |
| POST | `/api/v1/refunds/{id}/execute` | refund:order:execute |

## 权限

`refund:order:view|create|approve|execute`（种子见 `erp_permission_seed.sql`）。

## 数据库

无新表；复用 `TB_Refund*` / Process / Pay。

## 已知可接受遗留

- 部分退后不按比例冲销售业绩（有剩余则全留）  
- 套餐子项单独退、原路退支付通道  
- 产品库存回滚
