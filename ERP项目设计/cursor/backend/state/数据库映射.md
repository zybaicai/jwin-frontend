## 0. 映射总原则（本阶段锁定）

| # | 原则 |
|---|---|
| 1 | 优先 **A 完全复用** 旧表旧字段；能写进旧单据/账户表的，不新建平行业务表 |
| 2 | `TB_Channel` = **渠道商/介绍人主数据**（有地址、审批），**≠** 收银「销售渠道」字典 |
| 3 | 单据销售渠道复用 `*.Channel`（`TB_SaleBill.Channel nvarchar(50)` 等）；字典另建薄表（C） |
| 4 | 支付方式 ≠ 销售渠道：支付走 `TB_PayMethod` + `TB_SaleBillPay` |
| 5 | BillStatus：销售复用现有中文状态；耗卡旧码与中文并存时以实库/现码为准并文档化 |
| 6 | 价格优先级：特价 > 活动 > 区域 > 总部（CONF-001）；区域/活动主数据旧库缺失 → **C** |
| 7 | 次卡退款：仅剩次 × 销售时单次价值（CONF-003）；退款一律审批（CONF-004） |
| 8 | 无提成规则 → 金额 **0** 仍写业绩/提成快照行（CONF-005） |
| 9 | D 类结构调整默认不做；确需 D 必须人工确认 |
| 10 | 表名若含历史换行字符，Java/Mapper 用 bracket 引用；**不改名（避免 D/BI）** |

| 概念 | 落库 | Java |
