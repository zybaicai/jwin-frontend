## 推荐计算模型（草案，未锁定）

### 销售提成（无阶梯）

```text
对指定 month+store：
  读取本月已支付且未整单退款的销售行业绩 / 或按 Handler 拆分后的员工基数
  匹配规则优先级（建议）：
    HandlerJobTypeCommission
      > HandlerCommission
      > ProjectCommission
      > Scheme 默认
  金额 = 基数 × Rate + Fixed（Fixed 是否参与 V1 见 Q11）
  无匹配 → 0 仍写快照（CONF-005）
```

### 消耗提成（有阶梯）

```text
员工个人当月耗卡业绩合计（建议：PayPerformance+CardPerformance，不含赠送列）
  → 落入 TK_EmployeeCommission 区间 [Begin, End)
  → × Rate（+Fixed 策略同销售）
  无方案/无区间 → 0 仍写快照
```

### 月度批算（推荐 Q2=A）

```text
POST /commissions/calculate { month, storeId }
  → 覆盖「未结算」结果或按幂等键重算
  → 已结算禁止改（若 Q4 不做结算，则允许同月覆盖并记过程）
```
