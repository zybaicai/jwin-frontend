```text
现在进行数据库变更审查。

本项目数据库是高风险区域。

任何数据库修改必须非常谨慎。

扫描当前代码产生的：

CREATE TABLE
ALTER TABLE
ALTER COLUMN
ADD COLUMN
DROP
INDEX
CONSTRAINT
SQL

逐条检查。

每个变更必须回答：

1. 为什么必须改数据库？
2. 原有表能否复用？
3. 原字段能否复用？
4. 为什么不能复用？
5. 新字段是什么？
6. 类型是什么？
7. NULL是什么？
8. 默认值是什么？
9. 是否影响旧数据？
10. 是否影响BI？
11. 是否影响旧系统？
12. 是否可以回滚？
13. 是否需要数据迁移？
14. 是否需要人工确认？

风险等级：

P0：
删除表/字段/破坏历史数据

P1：
改变原字段语义或类型

P2：
新增字段

P3：
新增非核心辅助表

未经人工确认：

禁止执行P0/P1。

特别检查：

是否出现为了代码方便而重新设计数据库。

如果发现：

立即停止。

输出：

《数据库变更审查报告》
```
